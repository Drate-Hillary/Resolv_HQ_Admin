READING THE DIAGRAM

- Solid arrows are built and working today; dashed arrows are either a
  safety path that only fires on a violation (Boundary -> API) or a
  fallback path.
- Loaders is the single authorization boundary in the whole system: every
  tool and every prompt context is built from data this one step already
  scoped to req.user.id — no tool has its own selector argument that
  could name a different caller. See docs/tool-failure-auth-test-
  evidence.txt for an executed proof of this.
- Claude is drawn as reachable today because the gateway code is complete
  (docs/model-abstraction-and-rate-limiting.md) — the box's subtitle
  notes the one remaining gap (no live API key registered yet) so this
  diagram doesn't overclaim what's running versus what's wired.
